draft/assets — design assets for the data page and companion site

draft/assets/README.md · 52 lines · 5 KB · 727 words

Download raw All docs

Small, licensed assets used by tools/build-map-page.py to build draft/map-table-prototype.html as a single self-contained file (fonts, emblem, favicon, interface icons, geometry and the data are inlined at build time), and by tools/build-preview.py for the companion site. Brand provenance, licences and regeneration commands for the mark/icon set live in brand/README.md.

Design tokens (colour, type roles, spacing) follow the BetterGovPH transparency-portal theme (MIT), which mirrors budget.bettergov.ph: Figtree speaks, Inter works, JetBrains Mono labels, BetterGov blue #0b4fd9, white paper, ink rules.

The fonts are the latin variable subsets only (three files, ~108 KB total) so the page can be fully self-contained without shipping multi-script font families.

geo.json and coverage-geo.json are generated, not hand-edited: python3 tools/build-geo.py downloads and verifies the pinned high-resolution release archive (a release tag, not the mutable latest/ branch), extracts the 18 region files, projects them (Mercator, width 1000) and simplifies them at the TopoJSON-arc level for the map's render size (Douglas-Peucker 0.6 viewBox units; islets below ~4 km² dropped). The frame and the level of detail stay stable between runs; the Cordillera region, which read as a box, went from 36 to 324 points. geo-sources.json carries the exact source URL, licence, per-file SHA-256s, fetch timestamp, simplification parameters and per-region point counts. The boundaries remain CC BY-IGO: credit NAMRIA and the Philippine Statistics Authority through OCHA's Philippines COD-AB wherever the map is republished.

coverage-geo.json is the overlay layer for the provider filter: one simplified polygon per municipality/city, used only when the map is filtered by distribution utility. It is deliberately lighter than the region layer (Douglas-Peucker 1.4 viewBox units, integer relative path commands, tiny islets dropped unless they are an LGU's only land) because it is drawn as a filled overlay; the page inlines all 1,642 polygons. geo-sources.json records the per-file SHA-256s of the 88 province/district source files, the layer's simplification parameters and its own output hash. The service-area data that selects these polygons is published separately in data/seed/service_areas.csv (sources and licences in data/seed/service_area_sources.csv; methodology in research/coverage/README.md).
