# data/seed — real DOE workbook data, ingested and validated

This folder is generated by `tools/ingest-doe-rates.py` from snapshotted publisher
bytes. It is **not** hand-written sample data: rates come from the Department of
Energy's *Electricity Rates & Power Market Monitor* public workbook, retrieved
**2026-11-10** (4 tabs, 141 DU/EC rows, 107 month columns, 60,348 cells).

Two further seed files publish the provider service-area (coverage) layer:
`service_areas.csv` and `service_area_sources.csv`. They are assembled by
`tools/build-service-areas.py` from the MERALCO franchise law (RA 12146), the
OpenStreetMap Wiki operator table and the DOE workbook's region column (fallback),
then consumed by the same ingest. See "Coverage files" below.

The only illustrative file left here is `plants.csv` (sample plant records for the
next pipeline stage). It is not used by the current page and carries
`data_status=illustrative` on every row.

## Files

### `utilities.csv` (141 rows)

| column | meaning |
| --- | --- |
| `utility_code` | stable slug of the DOE utility name (`MERALCO`, `SOLECO`, `ILECO-II`…) |
| `utility_name` | name as published in the residential tab |
| `name_variants` | other tab spellings, e.g. `generation:DANECO` for `DANECO/NORDECO` |
| `du_type` | `PIOU` (private investor-owned) or `EC` (electric cooperative) |
| `grid_connection` | `ONGRID`, `OFFGRID`, or `CONFLICT` when tabs disagree 2–2 |
| `region_psgc` … `island_group` | PSA PSGC 10-digit region code, short/full name, island group |
| `latest_month` | latest month with published data (`2026-10`) |
| `res_latest`, `com_latest`, `ind_latest`, `gen_latest` | latest published value per customer class (blank = NDA) |
| `res_delta_mom_pct` | residential change vs previous month, where both exist |
| `data_status` | `published` / `partial` / `nda` for the latest month |
| `source_id`, `extraction_method`, `confidence` | provenance (`csv_export`, `verified`) |
| `retrieved_at`, `source_row` | retrieval timestamp and the workbook row the record came from |
| `coverage_source_ids` | `;`-joined source ids backing the published service area (`service_area_sources.csv`) |
| `coverage_detail` | strongest published coverage level: `lgu`, `barangay` or `region` (fallback) |
| `coverage_lgu_count` | number of LGU-level published coverage rows for the utility |
| `coverage_regions` | `;`-joined PSGC regions the published coverage rows touch (may exceed the one DOE region) |

### `regions.csv` (18 rows)

One row per PSGC region, with the **unweighted median and mean of the latest
published residential rate across reporting DUs** (Oct 2026), reporting counts,
min/max, and the same for commercial/industrial/generation medians. These are the
numbers behind the map.

### `rates_monthly.csv` (60,348 rows, ~6.4 MB)

Tidy long format: `utility_code, utility_name, customer_class, month, rate_php_kwh,
data_status, source_id, extraction_method, confidence, retrieved_at` — 141 utilities
× 107 header months × 4 customer classes. `data_status` preserves the difference
between a published value, `NDA` (publisher says no data), and `missing` (blank cell).
No value is imputed.

### `sources.csv` (4 rows)

One row per workbook tab: page URL, Google Sheet id, `tab_gid`, class, months
covered, cell count, retrieval timestamp, extraction method, **full SHA-256 of the
raw snapshot**, licence note (no explicit DOE licence found — reuse terms to confirm),
and the raw snapshot path.

### `service_areas.csv` (one row per covered area)

Tidy coverage rows assembled by `tools/build-service-areas.py` from published sources:
`utility_code,source_id,area_level,region_psgc,province_psgc,province_name,adm3_psgc,lgu_name,adm4_psgc,barangay_name,coverage_note`.

| column | meaning |
| --- | --- |
| `utility_code` | joins `utilities.csv` (stable utility slug) |
| `source_id` | joins `service_area_sources.csv`; the source backing this row |
| `area_level` | `lgu` (covered city/municipality), `barangay` (covered barangay) or `region` (single fallback row) |
| `region_psgc`, `province_psgc`, `province_name` | PSGC region + province (or NCR district) hierarchy; province fields blank on region rows |
| `adm3_psgc`, `lgu_name` | canonical 10-digit city/municipality PSGC + name; blank on region rows |
| `adm4_psgc`, `barangay_name` | barangay PSGC + name on `barangay` rows only; blank otherwise |
| `coverage_note` | the source's own qualification (partial province, barangay-only, region fallback, law override) |

In the current snapshot: **1,665 rows = 1,648 LGU rows + 17 Pampanga barangay
rows, zero region fallback rows** (all 141 utilities have LGU-level coverage).
A utility with no LGU-level source would get exactly one `region` fallback row equal
to its DOE region — an honest "not sourced at LGU level", never a guessed LGU; that
path exists but is not exercised by the current data. LGU-level rows are the
legislative/operator franchise area, not verified household billing territory.
Three utilities (PROSIELCO, SIASELCO, SULECO) publish coverage in a different region
than their DOE workbook row because PSGC 3Q 2026 reassigned Sulu to Region IX and
Siquijor to NIR; `coverage_note` documents it and it is not an error.

### `service_area_sources.csv` (one row per coverage source)

`source_id,publisher,dataset_title,page_url,revision_id,retrieved_at,license,attribution,notes`.
Current sources:

| source_id | source | licence / terms |
| --- | --- | --- |
| `SRC-RA-12146` | RA 12146 Section 1 — MERALCO franchise (Supreme Court e-Library text) | Public document (Philippine law); works of the Government are not subject to copyright (IP Code, Sec. 176) |
| `SRC-OSM-OPERATORS` | OpenStreetMap Wiki "Power networks/Philippines/Operators" (LGU franchise areas) | **CC BY-SA 2.0** — attribution required; share-alike applies to coverage derived from it |
| `SRC-WIKI-DUS` | Wikipedia "List of electric distribution utilities in the Philippines" (supplementary) | **CC BY-SA 4.0** — attribution + share-alike |
| `SRC-DOE-RATES` | DOE workbook region column (fallback only) | No explicit licence; reuse terms to be confirmed with DOE |

The coverage files are **not** DOE rate data, and because the layer merges OSM Wiki
(CC BY-SA 2.0) and Wikipedia (CC BY-SA 4.0) rows with the public-law MERALCO area,
**the combined coverage layer is a CC BY-SA derivative**: attribution is required
and share-alike applies to redistributions of the coverage data (the DOE rate data
is unaffected). Keep each source's attribution and licence with any republication of
the coverage rows.

### `validation.json`

The ingest report: 17 automated **rate** checks (all passing), the source-conflict
log, per-tab hashes/cell counts, latest/anchor-month statistics, and a separate
`coverage_checks` / `coverage` block (7 coverage checks: rows present, every utility
covered, LGU spot counts, valid PSGC, DOE region inside the service area). A failure
stops publication.

### `page-data.json` (~225 KB)

Compact payload derived from the CSVs and embedded into the self-contained page;
includes every utility's monthly residential series for the chart, plus each
utility's `coverage` block and the top-level `coverage` stats/sources/checks/files
(pinned rows/bytes/SHA-256 for the two coverage seed files).

### `plants.csv` (illustrative — not displayed)

Old sample records kept for the asset-layer stage. Every row is marked
`data_status=illustrative`; the current map does **not** show plants.

## Provenance, in one paragraph

The workbook was retrieved through Google's unauthenticated CSV export, the exact
bytes a browser would download. Each tab is snapshotted under
`data/raw/doe-rates/2026-11-10/` and hashed. Parsing keeps `published`, `NDA`,
`missing` and `invalid` as distinct states. The four tabs disagree in five places
(ILECO II/III grid status 2–2, CLPC region, an island label, and a `DANECO` /
`DANECO/NORDECO` name variant); each is logged in `validation.json`, resolved by
majority where possible, and published as `CONFLICT` where not. The June-2026
reference figures are asserted by the pipeline and reproduce
exactly (Meralco ₱14.48, SOLECO ₱16.57 at +32.2% m/m, BISELCO ₱24.92; 127 reporting
DUs, simple mean ₱12.29, median ₱12.10).

No explicit dataset licence was found on the DOE page. The figures are public
records; reuse terms should be confirmed with DOE (week-1 partnership ask).

Coverage provenance, in one paragraph: the service area layer is derived data, not
a DOE rate publication. MERALCO rows come from RA 12146 Section 1 (public law; the
franchise wins over OSM rows); the remaining LGU-level rows come from the
OpenStreetMap Wiki operator table, which compiles franchise areas "per Department of
Energy" and is licensed CC BY-SA 2.0 (attribution required, share-alike applies to
derived coverage data); Wikipedia's DU list (CC BY-SA 4.0) supplies supplementary
LGU areas where the OSM table has none. Utilities with no LGU-level source get a
single `region` fallback row from the DOE workbook region column, under the same
unconfirmed DOE terms as the rates. A franchise area is not verified billing
territory; region rows are a fallback, not LGU confirmation. The raw law text and
wiki revisions used are snapshotted under `research/source-snapshots/` and
`research/coverage/snapshots/`.
